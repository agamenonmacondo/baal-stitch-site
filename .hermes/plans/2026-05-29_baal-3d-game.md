# BAAL — Juego 3D para el Sitio Web

## Concepto: "Ritual de las 6 Puertas"

Un juego 3D inmersivo estilo **dark dungeon crawler** ambientado en el universo Muisca-jaguar de BAAL. El jugador avanza por 6 niveles (las 6 canciones del album), cada una con su atmosfera visual unica inspirada en las imagenes de la carpeta `inmutable/`.

## Mecanica

- **Vista:** Primera persona (FPS-style) con Three.js
- **Objetivo:** Avanzar por 6 camaras rituales (una por cancion), recolectando simbolos Muiscas
- **Controls:** WASD + mouse (desktop), touch joystick (mobile)
- **Musica:** Cada nivel reproduce el MP3 correspondiente del album
- **Victoria:** Al completar las 6 puertas, se revela el logo BAAL completo

## Arquitectura Tecnica

### Stack
- **Three.js** (CDN) — Motor 3D
- **Vanilla JS** — Sin framework, archivo unico
- **Web Audio API** — Reproduccion de MP3s sincronizada con el juego
- **Pointer Lock API** — Control mouse FPS en desktop
- **Touch events** — Joystick virtual en mobile

### Archivos
```
game/
  index.html          — Pagina del juego (entry point)
  js/
    main.js           — Loop principal, estados, UI
    scene.js          — Setup Three.js, luces, fog
    player.js         — Movimiento, colisiones
    levels.js          — Generacion de 6 niveles
    entities.js        — Simbolos Muiscas, portales
    audio.js           — Manager de audio por nivel
    controls.js        — Input keyboard/mouse/touch
    ui.js              — HUD, menus, transiciones
  css/
    game.css           — Estilos UI overlay
```

### Optimizaciones
- Geometrias procedurales (sin modelos externos)
- Texturas: las imagenes existentes como `MeshStandardMaterial.map`
- Fog por nivel (color de niebla = atmosfera del nivel)
- Audio lazy-load: solo carga el MP3 del nivel actual
- Mobile: joystick virtual + gyro opcional

## Flujo del Juego

1. **Pantalla de inicio:** Logo BAAL con efecto niebla, boton "ENTRAR AL RITUAL"
2. **Tutorial:** "Las 6 Puertas te esperan. Recoge los simbolos Muiscas para abrir cada puerta."
3. **Nivel I (Nova Lux):** Camara cosmica dorada, recolectar 3 simbolos
4. **Nivel II (Inmutable):** Templo Muisca con antorchas, 3 simbolos
5. **Nivel III (Chie Umbra):** Portal oscuro, 3 simbolos
6. **Nivel IV (Hasta la Muerte Invicto):** Ruinas, 3 simbolos
7. **Nivel V (Mil Pasos):** Desierto, 3 simbolos
8. **Nivel VI (Atlas):** Montanas, 3 simbolos + boss visual
9. **Victoria:** Logo BAAL completo, caratula del album, link al reproductor

## Riesgos

1. **Performance en mobile:** Three.js pesado — mitigar con geometrias simples, fog agresivo
2. **Audio autoplay:** Navegadores bloquean autoplay — requerir click del usuario antes de reproducir
3. **Texturas grandes:** Las imagenes PNG de inmutable/ son grandes — comprimir para WebGL
4. **Compatibilidad:** Pointer Lock API no funciona en iOS Safari — fallback a touch
